# 指尖绽放 · Hand Flower 🌸（鼠标版）

**鼠标控制虚拟手，手指张合控制花朵绽放。**

## 运行

```bash
cd hand-flower
node serve.mjs 8080
# 或 python -m http.server 8080 / npx serve .
```

浏览器打开 `http://localhost:8080`（Three.js 从 CDN 加载，首次需联网）。

## 交互

| 操作 | 效果 |
|---|---|
| 🖱 移动鼠标 | 3D 虚拟手跟随移动 |
| 滚轮 ↑↓ | 手指逐关节张开 / 卷曲 |
| 按住左键上下拖动 | 快速开合手指 |
| 双击 | 自动演示：开→合→开 |

手指张合度直接驱动花朵：**🖐 张开 = 盛放，✊ 握拳 = 花苞**；手掌位置同时牵引花心偏移。

## 技术要点

- **3D 虚拟手**：手掌 + 五指 × 3 关节层级结构，每关节按张合度差速卷曲
  （指尖弯折幅度更大，五指有相位差，握拳时手指同步收拢），指尖发光精灵
- **粒子花**：Three.js 约 12,600 粒子，GLSL 顶点着色器在 GPU 内完成
  花苞椭球 ⇄ 玫瑰形花瓣插值，CPU 每帧只传 `uBloom` uniform
- 零构建、零依赖：ES Module + CDN，任意静态服务器可跑
